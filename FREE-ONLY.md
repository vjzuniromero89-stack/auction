# FREE-ONLY MODE

This build intentionally disables ATTOM, PACER billable searches, First American/DataTree, CoreLogic and other paid data providers.

The engine uses free official public sources where available:
- CivilView auction discovery.
- Delaware CourtConnect civil cases/judgments.
- New Castle County parcel and Recorder entry points.
- Kent County property/deeds; Kent publishes guidance that viewing land documents is free.
- Sussex County public property search and Landmark recorder search/index.

A source being public does not mean automated scraping is authorized. Interactive systems remain MANUAL REVIEW REQUIRED. The app stores the exact property identifiers and direct official-source link so a human can verify and attach evidence.

No inaccessible/blocked/empty source is converted into NOT FOUND.
